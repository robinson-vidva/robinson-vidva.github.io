Tools & Demos

Free, open-source software for computational biology and drug discovery

Small, focused tools. The browser-based ones run entirely on your machine, with no data sent anywhere, and each released tool has its source on GitHub.

Use in your browser

DrugInteract

Educational drug-interaction reference that checks what each drug's FDA label says about another. Fully client-side, with no backend and no data collection.

JavaScript · openFDA · RxNorm

Open Code
enrichlite

Gene-set over-representation analysis (ORA) for human and mouse that runs entirely in the browser. Supports GO, Hallmark, and Reactome gene sets.

JavaScript · GO · Reactome · Hallmark

Open Code Article
drugtargets

Drug-target exploration and repurposing-hypothesis tool: Boolean gene queries, drug-to-targets lookup, and target-overlap similarity, built on Open Targets and openFDA.

TypeScript · Open Targets · openFDA

Open Code
neokine

Client-side pose visualization. Draws a MediaPipe skeleton and plots simple kinematics (joint angles, velocity, asymmetry) over an image, video, or webcam. Runs entirely in the browser; not a diagnostic tool.

JavaScript · MediaPipe · Kinematics

Open Code
neokine-labs Experimental

A playground in the neokine family: live MediaPipe Holistic pose and face tracking with real-time overlays and exploratory behavior heuristics. In-browser and experimental; not a diagnostic tool.

JavaScript · MediaPipe Holistic

Open Code

Platforms

MyVivarium

Open-source, cloud-based platform for managing research animal colonies, with QR-code cage cards and real-time IoT environmental monitoring. Published in CSBJ (2025); deployed at 3 partner labs supporting 200+ animals.

PHP · MySQL · IoT

Demo Code Article
MyVivarium v2

Version 2 of MyVivarium, shaped by feedback from partner labs: rebuilt workflows, a modernized stack (Docker, Playwright test suite), and broader experimental, husbandry, and operational support. In staged deployment at the University of Dayton (2026).

Redesign · Lab management · IoT
